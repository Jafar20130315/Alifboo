# Ushbu script haqida
Ushbu kod .html, .js va barcha boshqa turdagi dayllarni avtomatik tarzda yangi alifboga o'zgartiradi. O'zgartirishlar faqatgina yozuvlarga amal qiladi, URL va koddagi qismlarga zarar yetmaydi.
Bu baribir kod, shuning uchun ishlatishdan oldin asl kodingizni saqlab qo'yishingizni tavsiya qilaman. Agar biror nimaga zarar yetsa - javobgarlik mening zimmamda emas.

Yangi alifbo haqida ba'tafsil: [Kun.uz](https://kun.uz/news/2026/10/21/ozbek-lotin-alifbosini-takomillashtirishga-doir-qonun-prezident-tomonidan-imzolandi)
